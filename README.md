# SPA BOOKING

Приложение для онлайн-записи и бронирования услуг массажного салона.

## Стек

- React
- TypeScript
- Vite

## Запуск

npm install
npm run dev

Открой http://localhost:5173/

## Сборка

npm run build
npm run preview

## Структура

- `src/types/booking.ts` — типы основной сущности
- `src/data/mockBookings.ts` — демонстрационные записи
- `src/App.tsx` — стартовый экран
- `docs/project-spec.md` — спецификация проекта
